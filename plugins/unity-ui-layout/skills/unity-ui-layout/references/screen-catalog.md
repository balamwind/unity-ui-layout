# 화면 종류별 일반 구성

2단계 화면 목록과 4단계 명세 초안에 참고한다. 레퍼런스 게임과 다르면 레퍼런스를 따른다.

## 아웃게임

**타이틀 (UI_Title)**
- 전체 배경, 게임 로고(상단 1/3), "터치하여 시작" 텍스트 또는 시작 버튼(하단 1/3)
- 하단 모서리: 버전 텍스트, 필요 시 설정·계정 버튼

**메인 메뉴 (UI_MainMenu)**
- 모바일: 상단 재화바(StretchTop), 중앙 캐릭터·배너, 하단 탭바(StretchBottom) 또는 우측 큰 플레이 버튼
- PC: 좌측 세로 메뉴 버튼 목록(VerticalLayout), 우측 배경 아트

**설정 (UI_Settings)**
- 제목, 닫기 버튼(우상단), 탭(사운드/그래픽/조작), 항목별 라벨 + 슬라이더·토글
- 항목 목록은 ScrollRect 안에 VerticalLayout

**스테이지·레벨 선택 (UI_StageSelect)**
- 상단 제목·뒤로가기, 중앙 스테이지 목록 또는 월드맵, 하단 시작 버튼

**캐릭터·장비·인벤토리 (UI_Inventory 등)**
- 좌측 캐릭터 정보, 우측 아이템 그리드(GridLayout + ScrollRect), 하단 상세 정보

**상점 (UI_Shop)**
- 상단 재화바, 탭, 상품 카드 그리드

**로딩 (UI_Loading)**
- 전체 배경, 하단 진행바·팁 텍스트, sortingOrder 200

## 인게임

**HUD (UI_HUD)**
- 좌상단: 체력·레벨·경험치
- 상단 중앙: 타이머·웨이브·점수
- 우상단: 일시정지, 미니맵
- 모바일 하단: 좌측 조이스틱, 우측 스킬·공격 버튼
- 로그라이크: 상단 경험치바(StretchTop 얇게), 획득 스킬 아이콘 줄

**일시정지 (UI_Pause)**
- Dim + 중앙 창: 계속하기, 설정, 메인으로 버튼 (VerticalLayout)

**레벨업·선택지 (UI_LevelUp)**
- Dim + 카드 2~4장 가로 배치(HorizontalLayout), 카드마다 아이콘·이름·설명

## 결과·팝업

**결과 (UI_Result)**
- 승리/패배 제목, 기록(시간·처치 수 등), 보상 목록, 재시작·메인 버튼

**게임오버 (UI_GameOver)**
- 결과창과 합치는 경우가 많다. 기획서 확인 후 분리 여부를 유저에게 묻는다.

**확인 팝업 (UI_Popup_Confirm)**
- 제목, 본문, 확인·취소 버튼. 범용으로 하나만 만든다.

**토스트·알림 (UI_Toast)**
- 상단 또는 하단 중앙의 작은 패널, sortingOrder 200
